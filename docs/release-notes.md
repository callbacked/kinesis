# kinesis 0.1.0

a native macos client for the meta neural band. swipe between desktops, open mission control, control your music, and pinch + turn for volume or brightness. every gesture has a selectable assignment.

a short setup gets you connected and lets you practice. the hand lights up when gestures come through. there’s light and dark mode, a saved gesture count, and an option to start controls when the app opens. close the window and it stays in the menu bar.

the connection, gesture decoding, and dial are all swift. no python worker, glasses, or phone in the connection.

download the dmg and drag kinesis into applications. signed and notarized, for macos 14+ on apple silicon and intel.

handedness changes the illustration; the band keeps its existing calibration. cursor tracking and raw semg recording aren’t part of this app.
